`@fontsource` / `@fontsource-variable` npm packages (SIL Open Font License 1.1).

  https://github.com/Omnibus-Type/Archivo
- Space Mono (400, 700), Colophon Foundry / Google Fonts
- Inter (400, 500), The Inter Project Authors
  https://github.com/rsms/inter

Full license text: http://scripts.sil.org/OFL
